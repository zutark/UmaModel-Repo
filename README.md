# UmaModel Content Packs

Fan-made **Umamusume: Pretty Derby** character model & motion pack repository for the **[UmaModel](https://modrinth.com/mod/umamodel)** Minecraft NeoForge (`1.21.1`) mod, maintained by **@zutark**.

> **Note:** Character models and animations are packaged as `.umapk` content packs so original `Cygames, Inc.` game assets remain safely packaged for in-mod use rather than loose raw files. The mod JAR itself contains no third-party assets.

---

## Requirements

- **Minecraft:** `1.21.1`
- **Mod Loader:** `NeoForge`
- **Mod Version:** **UmaModel `0.1.2+`** — download from [Modrinth](https://modrinth.com/mod/umamodel)

---

## Download Content Pack

Download the latest `.umapk` content pack from **[Releases](https://github.com/zutark/UmaModel-Repo/releases)**:

- **24 Umamusume characters / 52 outfits**
- **7 VMD motion animations** (`idle`, `walk`, `run`, and emotes)

---

## Installation

1. Put the **UmaModel (`0.1.1+`)** `.jar` into your `.minecraft/mods/` folder.
2. Launch Minecraft and open the **UmaModel** menu (in-game keybind or `/umamodel`).
3. Click **`Packs Folder`** in the menu to open `.minecraft/config/umamodel/packs/`.
4. Drop the downloaded `.umapk` file (for example `umamodel-content-pack-0.1.1.umapk`) directly into `config/umamodel/packs/`:
   - **Do NOT extract or rename** the `.umapk` file.
5. Click **`Reload`** in the UmaModel menu to load your characters and animations.

---

## Server & Multiplayer Usage

- **Client-side content packs:** Content packs only need to be installed on clients (`config/umamodel/packs/`). **Never upload model packs to a Minecraft server.**
- Installing the clean **UmaModel** `.jar` on the server is optional and only syncs selected model IDs, scaling, and emotes between players who have the pack locally.
